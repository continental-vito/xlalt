⌥XL — Windows Alt shortcuts for Excel, PowerPoint and Word on Mac
=============================================

INSTALL
1. Right-click "Install XL.command" → Open → Open.
   (Right-click is needed the first time because the installer
   isn't notarized by Apple yet.)
2. When macOS asks for Accessibility permission, grant it to
   "ExcelAlt" in System Settings → Privacy & Security → Accessibility.
   The shortcuts activate on their own a couple of seconds later.

USE
• Open Excel, PowerPoint or Word, tap the ⌥ (Option) key once. The KeyTips
  panel appears and names the app whose shortcuts are active.
• Type a Windows sequence: H O I autofit, H V V paste values,
  H B A all borders, H 0 / H 9 decimals, = AutoSum, W F F freeze…
• Esc cancels. Holding ⌥ with another key still works as a normal
  Mac shortcut — only a solo tap starts a sequence.

MENU BAR
• The ⌥-chart icon in the menu bar: pause/resume, open the
  Shortcut Manager (add, edit, remove shortcuts), quit.

NOTES
• No dock icon by design; the app lives in the menu bar only.
• Your custom shortcuts are stored in
  ~/Library/Application Support/ExcelAlt/
• If shortcuts ever stop responding after a macOS update, remove
  the app's entry from Accessibility (with the "–" button) and
  run the installer again.
